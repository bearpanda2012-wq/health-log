# บันทึกสุขภาพ (Health Log)

เว็บแอปบันทึกความดันโลหิตและค่าสุขภาพอื่นๆ เก็บข้อมูลลง **Google Sheets ของคุณเอง**

🔗 **เปิดแอป:** https://bearpanda2012-wq.github.io/health-log/

- ความดัน (ตัวบน/ตัวล่าง/ชีพจร) แสดงระดับเป็นสีทันที พร้อมคำเตือนเมื่อค่าสูงมาก
- น้ำหนัก, น้ำตาลในเลือด, อุณหภูมิ, SpO2, ชั่วโมงนอน, การกินยา, อาการ, โน้ต
- ประวัติพร้อมสรุปค่าเฉลี่ย, กราฟแนวโน้ม, ส่งออก CSV
- ใช้บนมือถือได้ เพิ่มไว้ที่หน้าจอหลักได้ รองรับโหมดมืด

## โครงสร้าง

```
index.html            ← หน้าเว็บ (GitHub Pages)
apps-script/Code.gs   ← API ที่อ่าน/เขียน Google Sheet (วางใน Apps Script)
```

ถ้ายังไม่ได้เชื่อมชีต แอปจะทำงานใน **โหมดทดลอง** และเก็บข้อมูลไว้ในเบราว์เซอร์นั้นเครื่องเดียว

## ตั้งค่า Google Sheets (ครั้งเดียว)

1. สร้าง Google Sheet ใหม่ ไปที่ **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมออก แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) กดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **Run** จากนั้นอนุญาตสิทธิ์
   (ถ้าเจอ "Google hasn't verified this app" ให้กด Advanced → Go to … → Allow)
   แล้วคัดลอก **รหัสลับ** จาก Execution log
4. ไปที่ **Deploy → New deployment →** ⚙ **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก **Web App URL** (ลงท้ายด้วย `/exec`)
6. เปิดแอป ไปที่แท็บ **ตั้งค่า** วาง URL และรหัสลับ แล้วกด **ทดสอบและบันทึก**
7. ใช้บนมือถือ: ในหน้าตั้งค่า กด **คัดลอกลิงก์ตั้งค่า** แล้วเปิดลิงก์นั้นบนมือถือ จากนั้นกด **Add to Home Screen**

### ความปลอดภัย
- โค้ดนี้อยู่ใน repo สาธารณะ แต่**ข้อมูลสุขภาพอยู่ในชีตของคุณเท่านั้น**
- API จะตอบเฉพาะคำขอที่มีรหัสลับถูกต้อง ห้ามแชร์รหัสลับหรือลิงก์ตั้งค่าให้ใคร
- ถ้าสงสัยว่ารหัสหลุด ให้รัน `resetKey()` ใน Apps Script แล้วตั้งค่าใหม่ในทุกเครื่อง

### เมื่อแก้โค้ดใน Apps Script
ไปที่ Deploy → **Manage deployments** → ✏️ → Version: **New version** → Deploy (URL เดิมยังใช้ได้)
